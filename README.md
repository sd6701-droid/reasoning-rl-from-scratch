# Reasoning RL from Scratch

Implementation work for Assignment 3 of Greg Durrett's *Building LLM Reasoners* course (Spring 2026).

Course page: https://gregdurrett.github.io/courses/sp2026/index.html

## Layout
| Path | Contents |
|------|----------|
| `hw3/` | Assignment 3 — code, docs, and writeup |
| `papers/` | Course readings by week (see `papers/papers.tsv`) |

`hw3/` has `docs/` (assignment PDF), `code/`, and `writeup/`.

## Papers
Run `./papers/download.sh` from a machine with arXiv access. Papers with no
arXiv ID are listed in `papers/MANUAL.md`.
